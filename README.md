# Базы данных

Лабораторные работы по базам данных. Предметная область — склад,
СУБД — PostgreSQL.

## Ветки

Работы идут последовательно: каждая следующая ветка содержит предыдущие лабы.

| Ветка | Лабораторные |
| --- | --- |
| `lab_01` | 1 |
| `lab_02` | 1–2 |
| `lab_03` | 1–3 |
| `lab_04` | 1–4 |
| `lab_05` | 1–5 |
| `lab_06` | 1–6 |
| `main` | Последняя собранная версия; сейчас 1–6 |

Файлы каждой работы находятся в каталоге `lab_XX/`. Команды и пояснения
к работе лежат в её каталоге.

## Работа с репозиторием

Переключиться на нужную лабу:

```bash
git switch lab_05
```

Перед переключением сохрани изменения коммитом или через `git stash`.
Ветки указывают на последовательные этапы одной истории; при объединении
без новых расходящихся коммитов доступен fast-forward.

Начать следующую работу:

```bash
git switch lab_06
git switch -c lab_07
```

Сообщения коммитов: `lab_06`, `lab_06: prepare`, `lab_06: defence`.
