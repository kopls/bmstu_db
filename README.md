# Базы данных

Лабораторные работы по базам данных. Предметная область — склад, СУБД — PostgreSQL.

- **ЛР 1** — проектирование базы, создание таблиц и генерация данных.
- **ЛР 2** — SQL-запросы: выборки, соединения, подзапросы и оконные функции.
- **ЛР 3** — функции, процедуры и триггеры на PL/pgSQL.
- **ЛР 4** — функции, процедуры и триггеры на PL/Python.
- **ЛР 5** — работа с JSON и JSONB.
- **ЛР 6** — консольное приложение на Python для работы с базой.
- **ЛР 7** — LINQ в C#: работа с объектами, XML и PostgreSQL.
- **ЛР 8** — загрузка JSON с поставщиками в базу через Apache NiFi.
- **ЛР 9** — кеширование запросов в Redis и сравнение времени выполнения.
- **ЛР 10** — визуализация данных склада в Grafana.
